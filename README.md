# Интерактивный сайт-подарок: «Папа, открой подарок» ✨

Красивый интерактивный сайт на день рождения папы. Это не обычная открытка, а цифровая семейная история, которую папа проходит самостоятельно шаг за шагом.

---

## 🎁 Структура разделов

1. **Главный экран — Подарочная коробка**: 3D-коробка с золотой лентой, реалистичной анимацией развязывания, подъёма крышки, тёплого золотого свечения и частиц. Есть кнопка быстрого пропуска.
2. **Первое поздравление**: Торжественный заголовок *«С днём рождения, папа!»*, персональное трогательное поздравление и тёплые слова от семьи.
3. **Семейная фотогалерея**: Карточки с эффектом объёма и 3D-наклона, полноэкранный просмотрщик (лайтбокс) с поддержкой свайпов, стрелок клавиатуры, зума, подписей и дат событий.
4. **Интерактивная книга воспоминаний**: Цифровой альбом *«Помнишь этот момент?»* с перелистыванием страниц и памятными историями.
5. **Послания от близких**: Интерактивные конверты (*«От сына»*, *«От мамы»*, *«От бабушки и дедушки»*, *«От всей семьи»*). При нажатии конверт раскрывается, показывая личное письмо, фото и встроенный аудиоплеер с голосовым поздравлением.
6. **Мини-игра «Угадай воспоминание»**: Семейная викторина с вариантами ответа, без штрафов, с показом полной фотографии и объяснения.
7. **Коробка с маленькими сюрпризами**: Несколько интерактивных коробочек (*«Улыбнись»*, *«Вспомни»*, *«Прочитай»*, *«Посмотри»*, *«Главный сюрприз»*).
8. **Коробка с совместными планами**: Раздел *«Время, которое мы проведём вместе»* с карточками идей и возможностью выбрать понравившиеся варианты.
9. **Финальный экран**: Большая общая семейная фотография, золотой салют конфетти, тёплые слова любви и благодарности, возможность перезапустить историю или включить видеопоздравление.

## 📸 Как добавить ваши реальные фотографии

Все тексты и материалы вынесены в отдельный удобный файл: **`src/data/giftContent.ts`**.

1. Положите ваши фотографии в папку `public/photos/` (например, `papa1.jpg`, `family.jpg`, `childhood.jpg`).
2. Откройте `src/data/giftContent.ts` и укажите путь к фото:
   ```ts
   url: '/photos/papa1.jpg'
   // или прямую ссылку на фото из облака / соцсетей
   ```
3. При необходимости отредактируйте тексты, вопросы викторины, даты и имена авторов поздравлений.

## 🎶 Фоновая музыка

На сайте встроена фоновая музыкальная тема (кнопка в правом верхнем углу). Музыка не запускается автоматически, а включается папой по желанию. 
Если вы хотите использовать собственный MP3-файл:
1. Положите файл мелодии в `public/audio/melody.mp3`.
2. В файле `src/data/giftContent.ts` раскомментируйте строчку:
   ```ts
   customAudioUrl: '/audio/melody.mp3'
   ```

## 🌐 Публикация в интернете (GitHub Pages / Netlify / Render)

### GitHub Pages (Автоматически):
1. В репозитории на GitHub перейдите в **Settings** -> **Pages**.
2. В разделе **Build and deployment** выберите **Source: GitHub Actions**.
3. При каждом `git push` сайт будет автоматически собираться и публиковаться по адресу:
   `https://<ваш-логин>.github.io/<имя-репозитория>/`

### Netlify:
- Перетащите папку `dist` в [Netlify Drop](https://app.netlify.com/drop) для мгновенной публикации ссылки за 5 секунд!
